# OpenSCAD Enclosure for 3.5" ESP32‑S3 Display

## Overview

This repository contains a **parametric 3‑D printable enclosure** for the 3.5" ESP32‑S3 LCD display (commonly referenced as ESP32‑3248S035C / S3 version).  The enclosure is split into a **front cover** and a **rear cover**, designed to mate securely while providing cut‑outs for all required connectors, buttons, a microphone, an on‑board RGB LED, and mounting hardware.

## Hardware Specifications & Compatibility

- **Board**: Designed for the ESP32‑S3 3.5" IPS Touch Screen Development Board (front‑mic + rear RGB LED) – PCB dimensions **101.50 × 54.50 mm**.  See the [LCDWiki reference](https://www.lcdwiki.com/3.5inch_ESP32-S3_Display).
- **Mounting hardware**:
  - **Bolts**: Four ISO7380 M3 Hex Socket Button Head Cap Screws – see [AliExpress](https://www.aliexpress.com/item/1005005075572657.html).
  - **Nuts**: Four M3 Hexagonal nuts – see [AliExpress](https://www.aliexpress.com/item/1005003994209489.html).
  - **Recommended bolt length**: **M3 × 10 mm** (provides proper engagement of the nut pocket without protruding).
- **Additional components**:
  - USB‑C power port, TF‑card slot, reset (pin‑hole) button, boot button, front‑face microphone grill, rear RGB‑LED grill.

## Enclosure Design Details (`openscad/enclosure.scad`)

- **Front Cover**
  - Low‑profile countersunk recesses for M3 screws.
  - 3 × 3 microphone grill (top‑right bezel).
  - Cut‑outs for the capacitive touch panel and LCD backlight.
- **Rear Cover**
  - 5 mm standoffs for PCB clearance.
  - Hexagonal nut traps (depth 4 mm) for secure fastening.
  - Cut‑outs for USB‑C, TF‑card, reset pinhole, boot button, and RGB‑LED grill.
- **Alignment Lip**: 1.5 mm lip on the rear cover mates with a matching groove on the front cover to block dust and ambient light.

## Automation & Build Scripts

- `openscad/build.sh` – convenience script to render the STL files for each part and generate preview PNGs.
- `.gitignore` – excludes generated `.stl` files from the repository while preserving source code and preview assets.

## CI/CD (`.github/workflows/build-stls.yml`)

- **OpenSCAD compilation** runs on every PR and push using `xvfb-run --auto-servernum` for headless rendering.
- STL files are built and archived as assets on a pre‑release `latest` tag when merged to `main`.
- Generated PNG previews are committed back to the branch and displayed in the GitHub Action job summary for quick visual verification.
